# PixelVault

**Agent-first image hosting for developers and AI agents.** Upload an image, get a CDN URL back. Free tier, no credit card.

[pixelvault.dev](https://pixelvault.dev) · [Docs](https://pixelvault.dev/docs/) · [Image hosting API](https://pixelvault.dev/image-hosting-api/) · [OpenAPI spec](https://api.pixelvault.dev/openapi.json)

## Ways to use it

| Repo | What it is |
|---|---|
| [`cli`](https://github.com/pixelvault-dev/cli) | Command-line client |
| [`sdk-js`](https://github.com/pixelvault-dev/sdk-js) · [`sdk-python`](https://github.com/pixelvault-dev/sdk-python) | Official JavaScript/TypeScript and Python SDKs |
| [`skill`](https://github.com/pixelvault-dev/skill) | Agent skills for Claude Code, Codex, Cursor and other AI agents |
| [`mcp-local`](https://github.com/pixelvault-dev/mcp-local) | Local (stdio) MCP server. A remote one runs at `mcp.pixelvault.dev` |
| [`screenshots-action`](https://github.com/pixelvault-dev/screenshots-action) | GitHub Action: host CI screenshots and post them to the pull request |
| [`n8n-nodes-pixelvault`](https://github.com/pixelvault-dev/n8n-nodes-pixelvault) | n8n community node |
| [`desktop`](https://github.com/pixelvault-dev/desktop) · [`homebrew-tap`](https://github.com/pixelvault-dev/homebrew-tap) | Menubar app: copy an image, paste a hosted URL |
